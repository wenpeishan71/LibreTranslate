# LibreTranslate 校园版 · 中俄双语校园场景

基于 [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) 的校园中俄双语工具试点。
**本仓库不改动翻译引擎本体**，所有校园场景相关内容都在 `campus/` 目录中。

## 场景定位：通知与邮件的中俄对照生成

中外合办院校每周都会收发大量俄语/中文通知：教务通知、课程安排、活动邮件、课件标题。
机器翻译"直翻"这类文本最大的问题不是语法，而是**专有内容翻错**：

- 课程术语（"计量经济学" ≠ "经济计量学"）
- 课程编号与缩写（MT-101、GPA、CAS —— 根本不该被翻译）
- 人名（中文师生姓名的俄语音译、俄语教师姓名保留原文）

## 解决方案：术语表优先，翻译引擎其次

```
原文 → ①术语预检（查表，保护/替换术语）→ ②LibreTranslate 翻译 → ③术语回填 → ④自动排成中俄对照格式
```

- `terminology_zh_ru.csv` —— 校园术语库（种子版，可持续积累）
- `glossary_precheck.py` —— 术语预检脚本，演示 ①③④ 三步

核心思想：**把"容易翻错的词"从翻译引擎手里拿回来**，让引擎只负责翻它擅长的普通句子。

## 为什么值得做

| | 校园术语库方案 | 直接用商业翻译服务 |
|---|---|---|
| 术语准确性 | 可持续积累、可校对，越用越准 | 黑盒，专有名词经常翻错 |
| 数据隐私 | 自托管，数据不出校 | 数据发往第三方 |
| 成本 | 开源免费（AGPL-3.0） | 按量付费 |
| 可推广 | 同类中外合办院校直接复用 | — |

## 开源合规（AGPL-3.0）

- 本仓库全程公开，基于 AGPL-3.0 许可；
- 仅供校园内非商业使用；
- 若未来对外提供网络翻译服务，将按 AGPL-3.0 要求向使用者开放修改后的完整源码。

## 后续计划

1. 术语库扩充机制：师生提交 → 社团校对 → 入库（详见 `terminology_format.md`）
2. 浏览器插件：选中文本一键中俄对照
3. 邮件/通知模板：粘贴原文，输出排版好的中俄对照版
