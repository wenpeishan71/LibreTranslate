# LibreTranslate 校园版 · 中俄双语校园场景

基于 [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) 的校园中俄双语工具试点。
**本仓库不改动翻译引擎本体**，所有校园场景相关内容都在 `campus/` 目录中。

## 场景定位：通知与邮件的中俄对照生成

中外合办院校每周都会收发大量俄语/中文通知：教务通知、课程安排、活动邮件、课件标题。
机器翻译"直翻"这类文本最大的问题不是语法，而是**专有内容翻错**：

- 课程术语（"计量经济学" ≠ "经济计量学"）
- 课程编号与缩写（MT-101、GPA、CAS —— 根本不该被翻译）
- 人名（中文师生姓名的俄语音译、俄语教师姓名保留原文）

## 解决方案：术语表优先，翻译引擎其次

```
原文 → ①术语预检（查表，保护/替换术语）→ ②LibreTranslate 翻译 → ③术语回填 → ④自动排成中俄对照格式
```

- `terminology_zh_ru.csv` —— 校园术语库（种子版，可持续积累）
- `glossary_precheck.py` —— 术语预检脚本，演示 ①③④ 三步
- `name_translit.py` + `names_zh_ru.csv` —— 人名音译：定译表优先，其次规则转写，俄语姓名保留原文
- `notice_template.py` —— 通知 / 邮件的中俄对照排版，一句命令输出可直接粘贴的对照版

核心思想：**把"容易翻错的词"从翻译引擎手里拿回来**，让引擎只负责翻它擅长的普通句子。

## 人名音译（材料切入点③）

人名是最容易翻错又最难校对的一类，本项目的处理原则是**可追溯、不冒充**：

| 情况 | 处理方式 | 准确性 |
|---|---|---|
| 已登记人名（`names_zh_ru.csv`） | 直接取人工确认的定译 | 最高，优先使用 |
| 姓名用字在内置迷你拼音表内 | 拼出拼音 → 按规则转写成西里尔 | 可用，建议人工过目 |
| 迷你表未收录的用字 | 明确标记"待人工核对" | 不用机器结果冒充定译 |
| 俄语教师姓名（西里尔字母） | 原样保留，不做转写 | — |

之所以不内置上万条汉字拼音字典：本项目坚持**离线、零依赖**，宁可少翻几个、标出来让人补，也不给出无法追溯的结果。

## 通知 / 邮件一键对照（材料切入点②）

```bash
# 第一行=标题，最后一行=落款，中间=正文
python notice_template.py --file notice_demo.txt

# 或直接在命令行给文本
python notice_template.py --title "关于期末考试安排的通知" \
    --body "本学期《计量经济学》期末考试于 MT-101 教室举行，请携带学生证。" \
    --sign "教务处"

# 不连翻译引擎时用 --dry-run 查看术语命中与排版
python notice_template.py --file notice_demo.txt --dry-run
```

输出示例（`--dry-run`，未调翻译引擎，仅展示术语回填与排版结构）：

```
════════ 校园通知（中俄对照）════════
【标题 / Заголовок】
  中：关于期末考试安排的通知
  俄：关于экзамен安排的通知

【正文 / Текст】
  中：本学期《计量经济学》期末考试于MT-101教室举行，请携带学生证。
  俄：本семестр《Эконометрика》экзамен于MT-101教室举行，请携带студенческий билет。
  中：王明同学需补考高等数学，GPA按教务处规定计算。
  俄：Ван Мин同学需пересдачаВысшая математика，GPA按учебный отдел规定计算。

【落款 / Подпись】
  中：教务处
  俄：учебный отдел
```

术语、人名（王明 → Ван Мин）、缩写（GPA）、课程编号（MT-101）全部命中并保护。

## 为什么值得做

| | 校园术语库方案 | 直接用商业翻译服务 |
|---|---|---|
| 术语准确性 | 可持续积累、可校对，越用越准 | 黑盒，专有名词经常翻错 |
| 数据隐私 | 自托管，数据不出校 | 数据发往第三方 |
| 成本 | 开源免费（AGPL-3.0） | 按量付费 |
| 可推广 | 同类中外合办院校直接复用 | — |

## 开源合规（AGPL-3.0）

- 本仓库全程公开，基于 AGPL-3.0 许可；
- 仅供校园内非商业使用；
- 若未来对外提供网络翻译服务，将按 AGPL-3.0 要求向使用者开放修改后的完整源码；
- 校园场景相关的通用能力（如术语表优先机制）成熟后，会整理成独立 PR 回馈上游 LibreTranslate。

## 后续计划

1. 术语库扩充机制：师生提交 → 社团校对 → 入库（详见 `terminology_format.md`）
2. 浏览器插件：选中文本一键中俄对照
3. 批量文档翻译：一次处理整份课件 / 通知合集
4. 人名迷你拼音表扩充，或接入开源拼音库（如 `pypinyin`）
